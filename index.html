02 // Purpose

Ideas become products here.

No Code Society is where UNSW students go from an idea to something people can actually click, usually in a single sitting.

The tools changed. Base44, Framer, Notion and Codex let one student do what used to take a team of engineers. We run workshops, build nights and hackathons so everyone at UNSW, from medicine to actuarial studies, knows how to use them.

02.1 // How we work
Build first

You leave every session with something working, not a page of notes.

Ship in public

Projects get demoed, judged by people who build for a living, and posted.

No gatekeeping
